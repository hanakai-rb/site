<div class="intro">
Hello. If you're reading this page, it's likely you already know a lot about Rails, but want to now learn about Hanami.

This learning process will involve breaking out of the patterns that Rails has enforced, and learning about Hanami's approach. There are going to be times in these guides where things will feel more "spread out". This is for the greater good! Hanami has taken the lessons learned from organising Rails applications and improved upon the foundations of Model-View-Controller by providing.

In this guide series, we'll set up a Hanami project and build it out. Along the way, we'll mention Rails patterns, and then show what the equivalent Hanami patterns are.

</div>
